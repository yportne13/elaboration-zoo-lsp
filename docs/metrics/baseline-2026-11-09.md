## 9. CI 门禁（`--check`）

`tools/gate_p0.sh` 调用 `python tools/metrics.py --check`（只看 exit code）。检查项与阈值（基线 = 本 JSON 的 `check_baseline`，缺失时用内置常量）：

| 检查项 | 阈值 |
|---|---|
| `src/` 非空行 | ≤ 基线 ×1.005（+0.5%） |
| 层内非空行 | ≤ 基线 ×1.005 |
| `unsafe`（层内） | 不得高于基线 |
| `panic!` / `.unwrap()` / `.expect()` / print 宏（层内） | 不得高于基线 |
| 归档非空行 / `.bak` 文件数 | 必须为 0（不得重新引入） |
| 跨层复制（Jaccard ≥90% / ≥95% 的对数） | 不得高于基线 |

**退出码策略（首轮选择）**：默认 `--check` 只打印 `WARN` 且 **exit 0**（不阻塞 CI，避免基线刚建立/清理进行中被误红）；加 `--strict` 才在 WARN 时 exit 1。P1 清理落地、基线稳定后建议把 `gate_p0.sh` 改为 `--check --strict`。基线缺失时自动退回内置阈值并在输出中标注 `baseline=builtin`。

```bash
python tools/metrics.py --check            # WARN+exit0（默认，advisory）
python tools/metrics.py --check --strict   # WARN+exit1（阻断）
python tools/metrics.py --check --baseline-json path/to/baseline.json
```
