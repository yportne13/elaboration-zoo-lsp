# L07/L08 builtin 改为 L13 式 PrimFunc（2026-11-10）

分支：`feat/all-layers-hardening`，提交 `0971ad2e`（merge `d635ddd1`）。

## 动机

同一份 builtin 有三种实现：

| 层 | 旧实现 | 问题 |
|---|---|---|
| L08 | λ 链体是裸 `Tm::Prim(name)`；eval 把**整个 env** clone 进 `Val::Prim` spine | 每次 prim 求值 O(env)；quote→eval 在任意 env 下可能捕获无关槽；语义依赖 canonical λ 链 |
| L07 | 零元 `Val::Prim` + 显式 App 链（`λ p1…pn. ((Prim name p1)…pn)`） | 正确、无 env 扫描，但仍有 Prim 特例 |
| L13 | `PrimFunc` 挂在 decl 条目上；无 `Tm::Prim`/`Val::Prim` | 最干净：builtin 是普通声明，force 用 decl 条目回调归约 |

本次把 **L07/L08 参考版** 的 builtin 注册/归约路径改成 L13 模型。

## 实现

1. `DeclEntry` 新增：
   - `prim: Option<PrimFunc>`：builtin 归约回调；
   - `eta: Option<Tm>`、`prim_names: Option<Rc<Vec<Span<String>>>>`：仅用于 quote/println 的 η 展示兼容。
2. `Cxt::add_builtin`：
   - 不再构造 `Tm::Prim`/λ 链；
   - builtin 条目的 value 是中性 `Val::Decl(自身名, [])`，类型照旧求值，`prim` 指向 `Infer::prim_reduce` 的闭包。
3. `force` 的 `Val::Decl` 分支：
   - 先查 decl 条目；若 `prim` 存在，按应用序强制 spine 实参后调用回调；
   - 回调返回 `Some` 就递归 force 结果；`None`（元数不足/卡住）保持中性 `Val::Decl` 继续累积实参。
4. `eval(Tm::Decl)`：
   - prim 条目返回中性 `Val::Decl`，不再展开 val（避免 η 壳/自引用递归）。
5. `quote(Val::Decl)`：
   - 仅为了兼容旧的 `println` 输出，把 builtin 按 `prim_names` η 展开（含 partial application；用 de Bruijn shift 构造剩余 λ），普通项仍是 decl + spine。
6. 旧 `Tm::Prim`/`Val::Prim` 变体保留，但 **参考版 builtin 不再构造它们**；fast twin 仍用旧实现，完整 twin 改造是独立后续项。

## 未做/风险

- fast twin 仍使用旧的 `Tm::Prim`/`Val::Prim`/`XCell::Prim` 路径；两侧语义一致由 parity 测试保障（现全绿）。
- 如果后续删除参考 `Tm::Prim`/`Val::Prim` 变体，需要同步 twin 的 export/force/eval/prim_registry；建议作为独立 PR。
- prim 纯度/force memo 目前没有 L13 的 `force_taint`/`FORCE_PRIM_MEMO` 机制（L07/L08 本来没有）；本轮只统一表示与归约入口，不引入新缓存。
