## 5. 刻意分歧登记（锚点）

1. **L08→L09 时代缺口族**：decl 表→global 哨兵、builtin/可变全局/文件 IO、
   特化合一 pm 状态、`Val::Match` pending splice、`struct_eq`、unify_fuel。
   锚点：`src/L09_mltt/README.md`；`L09/mod.rs:3-7`；`L09/bump_spine_iter.rs:655-661/1942`；
   `docs/review-l01l12/a3-r3.md:139,229`。
2. **L09/L10 无 unify/force fuel**：见 §1 结论表。锚点：本轮两份 README；
   `L07/mod.rs:245 UNIFY_FUEL`（对照存在面）。
3. **`Val::to_typ` Sum 参数槽剔除（flat_map/filter_map）**：非丢参 bug——
   (a) 实例登记侧 `to_typ()==None` 直接 Err "Not a type"（`elaboration.rs`
   ImplDecl 臂），实例断言永不含被剔形态；(b) 目标侧被剔后 arity 失配 →
   try_resolve 判不匹配 → "no instance"，不会选错实例；(c) trait_wrap 接收者
   路径**依赖**剔除：接收者类型 `List[?m]` 化为 `Construct("List",[])` 与
   `impl[T] Say for List[T]` 的 pattern 一阶匹配成功——改成整体 None 会让该
   合法形态从 Ok 变 Err（违反 BRIEF 硬约束 3）。锚点：`typeclass.rs` 内注释、
   快版 `val_to_typ` 注释。
4. **L09 unify(Match,Match) 无 struct_eq 快路径**：分支体经
   `avoid_recursive`（全局→rigid）重求值，自比较不再发散，与 L07/L08 的
   "真 decl 表展开 + struct_eq 短路"为两种同效架构。锚点：
   `L09/unification.rs` Match 臂注释、本轮 README。
5. **L10 mod.rs 内联 `#[test]`（~500 行）L09 没有**：演进（L10 自带单元
   测试；`e46ebdd` 已移除从未通过者），非缺口。
