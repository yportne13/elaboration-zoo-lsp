## 8. 补齐：完整 `LspSurface` 契约（2026-11-23 补）

最初的 L08 观察面是简版（只有 hover 元组向量）。现补齐到与 L07/L09–L12 **对等**：

- 新增 `src/L08_product_type/surface.rs`（L07 的平移）：`LspSurface`（hover / completion /
  `inlay_hint` / `println_spans` / `check_issues` / `failed_decls`）、`SurfaceQuery`、
  `hover_entry_at` / `hover_text_at` / `is_empty`、`raw_span`、`inlay_label`、
  `failed_decl_names`、`format_check_warning`；
- `run_with_surface` 返回 `(String, surface::LspSurface)`（原来是元组向量）；
- 新增两条通道的采集：
  - **println_spans**：推断前取 `Raw` 的 span，渲染后写入通道（与输出串一致）；
  - **inlay_hint**：`check` 的 `(Raw::Hole, a)` 臂补 `: <type>`（期望类型无未解 meta 才推），
    锚点 = 当前最内层 binder 尾 / 顶层 0。

测试补 2 例（`println_spans_are_collected` / `hole_inlay_is_collected`），`l08_lsp_surface` 从 86 → 88。
