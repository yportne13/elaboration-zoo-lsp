## 4. 参考版 vs 孪生版

孪生增量 = **改名 + 两处机制镜像 + 1 个负载**（README §6 原文即此四条），但规模仍 7593 行，
因为它是整套第二实现（arena + 打包 `V` tag + 迭代内核 + 双记忆化 + 稳态复用），
移植载体本身 ~7.5k 行/层，不是"镜像那两处"的成本。

| 孪生增量 | 锚点 |
|---|---|
| ①② 改名 + 类型级 `.mk` 剥链镜像（`XCell::Sum` 接收者臂逐句对应参考版） | README §6；`bump_spine_iter/machine.rs:1066-1127`（gate `1090`，卡住投影实例化 `1114-1116`） |
| ③ `(Obj,Obj)` 合同臂（扁平 spine 里显式化；裸×链统一处理，原"Obj 头不进同头"降为防御） | `bump_spine_iter/unify.rs:673-698` |
| ④ `struct_src(k)` 特色负载（4 层 Box + 浅值投影 def 链） | `bump_spine_iter/bench_src.rs:131` |
| P1/P2 镜像（`subst.rs:255`、`unify.rs:37`/`338`/`1017-1020`）+ 配方演进（常驻缓冲、`clear_round` 清 `spine.stack`、`decl_insert` 覆盖写：`machine.rs:196-207`、`1788`/`1819`） | 同左锚点 |

- **值表示**：参考版 Rc/Box 树 + 递归；孪生 bump arena + 打包字 + 显式工作栈。两版差异不是
  "优化开关"，改一处机制必须改两处（Obj 臂、occurs、预算各两处）。
- **parity 判据**：Ok 输出逐字节一致 / Err 判定一致；错误正文经 span 归一化（剥 `@ N[,M]`）
  后也逐字节比（README §9 二轮评审起）。静态 **95** = 60 个 lib 用例（带入 `#[path]`）
  + 33 个自有 parity + 2 个 2026-11-08 新守卫 `c1/c2`（`tests/l08_fast_parity.rs` 静态 35，
  含这 2 个；`assert_both_err_within` 同时钉"两侧都 Err"与耗时上界）。
- **已知偏差**：`Error` 单字段、span 全零（P10）；`unify_catch` 文案带 pretty 项 +
  `(fuel exhausted)` 尾注（`mod.rs:1365`）；**P3 是层间差异而非引擎差异**（两版同旧口径）。
- **只在参考版 / 只在孪生版**：参考版无 L12/L13 式独占机制；孪生独占稳态复用、常驻缓冲、
  消融开关（FACTS §4）。

## 7. 优劣评估

**优点**
1. **概念税最低**：核心机零新变体，struct 在 parser 就消失（`parser/mod.rs:546-570`）——"语法糖层"教科书样本，也解释了为什么下游无人继承它。
2. **增量边界可审计**：机制仅 2 处（`elaboration.rs:499-534`、`unification.rs:797-805`）+ 显示 1 处（`pretty.rs:185-194`）。
3. **双引擎收益实在**：孪生 struct 32.3× / strchain 38.4×（09-20 矩阵）；参考版从 decl COW 悬崖（struct basic 1728.7 ms）降到 134 ms。
4. **回归基线厚**：L07 黑盒 58+53 原样通过，加糖未破继承语义；限制文档诚实（README §7）。
5. **σ 迁移完成且两引擎同构**（`pm_defs` 零代码残留），且是唯一已部分回灌 11-08 加固的层 → 可当**回灌试验田**。

**缺点/风险**
1. **加固缺口最大**：P3/P5/P8/P10/P11 未迁；P3 使层间语义分叉（L07「无法判定」vs L08「分支不可达」），跨层对照会踩坑。
2. **诊断最弱**：`Error(String)` 无 span（`mod.rs:517`）、无 `UnifyKind` → 分不清"真冲突/预算耗尽"，靠 `unify_catch` 文案 hack（`mod.rs:1365`）。
3. **语言面浅**：struct 不能被 Con 模式解构、无元组式 struct、字段按行分隔、裸 spine 实参不接 `new`（README §7）。
4. **双引擎维护面积 ≈2.04×**（7593 / 3716），两版结构不同，机制改动必须双写。
5. **字符串约定 gate**：`contains(".mk")`（`elaboration.rs:499` / `machine.rs:1090`）把正确性押在"用户无法声明带点 case 名"上[推断]，隐性耦合易破。
6. **文档膨胀且部分过期**：405 行 README，基准表仍 09-18 口径（135.205 vs 09-20 的 134.159），§8 计数"以 Lead 实跑为准"。

| 教学清晰度 | 5 | 零核心机变体 + 脱糖一览；L07 是"为什么"，L08 是"怎么加糖" |
