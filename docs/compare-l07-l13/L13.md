## 4. σ 迁移五轮失败复盘（专节，答问题 2）

**事实链**（`docs/explicit-subst-refactor-status.md §4`、`docs/wip/README.md`）：
L07–L12 全部落地显式替换，L13 五轮尝试 + 5-agent 评审轮后**回退 HEAD**，补丁存档
`docs/wip/l13-explicit-subst-round*.patch`（round5 为累积超集）`[文档]`。

| 维度 | 实测证据 | 结论 |
|---|---|---|
| **规模** | 移植代码 8 文件 +1599−452；裸语言语料 65 例逐字节 diff=0；prelude 24 文件触发 **12,287 层 meta 解链**（`succ(?m₁):=?m₂…`），默认测试栈必溢出（parity 崩因）；FRCS_MEMO 长跑内存 13 GB 仍在涨 | 规模是**放大器**，不是首因 |
| **性能** | `l13bench prelude-core` basic：基线 22.4ms → 移植 1242ms；关 LSP 表 637ms ⇒ **纯 elaboration 仍 ~28×**；quote 最外层调用 63,953 来自 PM 编译器 | **主阻塞**（验收线 ≤1.5×） |
| **正确性** | 手工 GADT 覆盖回归（`Tuple2.mk(zero,cons)` 误报 non-exhaustive）**第五轮已在参考版修复**（`ArmEntry/FilterResult` 带逐列 σ、探测点 `wrap_sub`）；孪生**同病未修**（`Arm` 无 σ 字段、下降期 6 个构造点不带精化）⇒ **当前唯一已知 REF/TWIN 语义分歧**；另有 4 个既有 parity 失败（test14/`test_prove_term_pure`/`test_stuck_match_application`/`resident_compaction_*`） | 正确性**可修但没修完** |
| 副产物 | prelude 期 LSP 表总闸（`Infer.lsp_collect`）实测 21.1s→9.3s 零行为变更，**随回退撤下，master 无此改动**（`grep lsp_collect src/` 0 命中）| 已证的性能修复也没落地 |

**为什么失败**（机制层）：σ 下 `force(Rigid)` 不再查全局解表，精化只对"被 σ 包裹过的值"可见
⇒ ① 覆盖探测必须显式 `wrap_sub`（第五轮补）；② 观察面 quote/pretty 必须重建 VSub 值
（prelude 期 LSP 渲染曾占 ~11s）；③ **指针键 memo 失效**——`FORCE_MEMO` 按节点地址缓存，
带 σ 包裹的新 Rc 每轮必 miss，需"σ 内容寻址内化"才救得活；④ meta 解链只在 solve/occurs 侧
能治，force 兜不住。即：失败**不是单一原因**，是"性能 × 规模 × 观察面耦合"的合成，
其中正确性回归已在参考版闭环。

**L13 保持 `update_cxt` 对自身的意味**：
- 语义：与 L09–L12 旧路线一致，**保住基线行为**（65 例与 4 个既有 parity 失败都按旧语义）， 代价是 README §6.8 承认的路线级成本——`refresh` 每次精化从 `update_from` 起整段重求值 （`cxt.rs:1350`），嵌套 match 深负载下精化传播比 σ 重`[文档 README:409-412]`；但**未量化** （README 自认"未核实是否有量化对比"）。
- 性能：反而保住了指针键缓存（`FORCE_MEMO`/`ctor_hover_memo`）与 `typ_pretty` 的稳定性； σ 移植的 28× 回归说明在 L13 的 prelude 规模下，**改精化载体不是局部手术**。
- 继续迁移的最可行路径（round-6 清单，按性价比）：① 孪生镜像逐列精化（parity 前置，结构性改动）； ② 在 solve/occurs 侧断 meta 解链（环检测/深度上限）；③ σ 内容寻址 memo + PM 探测按 (构造子, 目标类型) 缓存；④ `lsp_collect` 总闸先单独落地（与 σ 无关、零行为变更，应立刻做）； ⑤ FRCS_MEMO 分代回收 + FORCE_MEMO 改 Weak。`[文档 wip:219-262]`

## 8. 优劣评估

**优点（≥3，带证据）**
1. **唯一端到端产品层**：LSP 默认孪生（`lib.rs:288-330`）、HDL prelude/emit、wasm 宿主、12 套
   LSP 套件——语言实现直接服务真实 IDE 与 HDL 生成，其它层没有。
2. **语言面最完整**：命名空间五级解析 + package/import + 全限定 decl 键 + class 两阶段 +
   BindingName + 原生 Nat + def replay，均在真实语料上验证（28.8k 行参考侧 + 16.4k 孪生）。
3. **双引擎收益最大区间被吃满**：大值负载 519–568×、prelude 2.2–2.3×；FORCE_MEMO 三支柱
   （keepalive/taint/version）与 PreludePool 所有权约束是高质量工程。
4. **观察面契约可复用**：push 期 quote→owned 是"跨 bump 生命周期"的通用解法（见 §5）。
5. **有完整的缺陷复盘文化**：UAF 根因（`Rc` 快照保命克隆）与 σ 五轮证据都留档可追溯。

**缺点/风险（≥3，带证据）**
1. **规模与维护**：52.7k 行合计、测试 13.5k 压在 `src/`；README 454 行但行号/计数大面积漂移
   （§9.4）；单文件 `mod.rs` 7.6k。
2. **精化路线落后一代**：唯一未迁 σ 的层，`refresh` 全槽重求值成本未量化，GADT 组合覆盖缺口
   与跨字段精化弱点仍存（README §6.8、§2.5）；σ 迁移失败证据说明"想改也难"。
3. **加固未回灌**：无 `occurs_transitive`/`MATCH_CMP_BUDGET`/`UnifyKind` 三档/span 修复
   （§9.2），与 L07 的健壮性差距是当前最大的层间语义差。
4. **观察面污染核心**：27 个 push 点写进 `elaboration.rs`；prelude 期渲染后清空是纯死工作
   （已证 21.1→9.3s 但未落地），说明耦合已产生可测成本。
5. **已知缺陷面宽**：文件 IO panic 无锁、单行 enum 假阴性、NAT 参数静默错位宽、并行 UAF
   （已修）、Stacked Borrows UB（`transmute`/别名写未清）。

**评估卡（1–5）**

| 维度 | 分 | 依据 |
|---|---:|---|
| 教学清晰度 | 2 | 语言核心被宿主/观察面/单文件巨兽淹没；机制参考应读 L07/L12 |
| 语义健全性 | 3 | 基线语义稳定；GADT 组合覆盖缺口、NAT 参数剩余 bug、单行 enum 假阴性 |
| 参考版性能 | 3 | 大值负载 4.5–7.5s（已优化到 18.6/85.2ms），match 0.215ms 同层第二梯队 |
| 孪生性能 | 5 | match 仅 1.25× 但大值 519–568×、prelude 2.2×，生产交互路径依赖它 |
| 可维护性 | 2 | 52.7k 行、测试入 `src/`、README 漂移、update_cxt 历史债、补丁未落地 |
| 测试强度 | 4 | 15 parity + 12 LSP 套件 + 587 lib；扣分在单行 enum 假阴性/组合缺口被钉为现状 |
| 生产就绪度 | 4 | 默认孪生引擎 + 29/30 HDL 示例；扣分在 18-utils 回落与内存/池约束 |

**L13 适合当什么**：**当产品/宿主实现维护**（LSP 引擎 + HDL prelude 基线），能继续演进；
**不适合当语言实现教学参考**（读 L07 学理论、读 L12 学 σ、读 L13 学"生产化要付什么代价"）。
若要长期维护：先抽公共 crate（parser/pretty/Synth 已共享，继续抽 typeclass/PM）、
补回灌加固、把观察面收敛为独立 crate 边界，再决定 update_cxt 是否值得第二次 σ 尝试。
