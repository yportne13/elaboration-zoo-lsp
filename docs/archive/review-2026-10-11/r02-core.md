## 2. 判读

### 正确性亮点(全部通过)
- **闭合算术在类型索引内归约**:`Eq(nat_add(2,3), 5) = rfl` 与
  `Eq(2+3, 5) = rfl` 均通过,打印 `Eq[Nat]::refl(5)`——NbE 的转换检查
  在 Eq 的索引位置做了完整的 δ+β+primop 归约。
- **非累积宇宙**:`Type 0 : Type 5` 被拒(can't unify)——与 README 声明
  一致(转换要求层级相等)。
- **终止检查器**:裸自调用 `def bad(n: Nat): Nat = bad(n)` 被拒
  ("cannot prove termination")。
- **ack(2,3)=9**:嵌套递归求值正确。
- **假等式失败**:`Eq(nat_add(2,3), 6) = rfl` 被拒——没有把 rfl 万能化。

### 我方用法纠错(记入方法论,非 bug)
- `refl` 是**构造子**(需要参数);裸自反证明是 `rfl`。四条探针(c14/16/18/19)
  最初误用 `refl`,全数失败;改 `rfl` 后通过。另外 `eq` 是 prelude 名,
  用户 def 撞名会报 redefine(c14 重命名后通过)。

### 记录的 quirk
- **`nat_div(5, 0) = 5`**:除零返回被除数(饱和语义),不挂不崩。文档未写明
  (docs/hdl-language-spec 的硬件 `/` 另有约定);建议在 syntax.md 标注。
- `nat_mod` 不存在(prelude 只有 nat_div);c32 探针因此保留 error 预期。
- `Vec` 不在 prelude(语法文档示例引用了它,但 core prelude 未提供)——
  文档与 prelude 的差异,记遗留。
