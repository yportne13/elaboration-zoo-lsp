### 1.2 [P1·已修·待压测证实] PRELUDE_POOL 交接 TLS 析构序地雷（R2 §3.2 验证配方实施，授权升级）

- 位置：`src/L13_namespace/mod.rs` `impl Drop for PreludeSlot`（:3519-3545）+ 配套两处。
- **改动**：
  1. `Drop for PreludeSlot` 在 `pool.lock()` **之前**插入 `force_memo_clear();` 与
     `declb_cache_clear();`——把本线程仍钉着池化状态共享 Rc 图的两个线程本地缓存降回空，使
     "推池时持最后引用"的 `PoolState` unsafe-Send 论证前提在**任何 TLS 初始化序下**都成立
     （lazy TLS 按初始化逆序析构；若 FORCE_MEMO/DECLB_CACHE 先于 PRELUDE_CACHE 初始化，原实现
     会在推池解锁后、与取用线程无 happens-before 边地递减共享节点引用计数 → 计数漂移 → UAF →
     STATUS_ACCESS_VIOLATION）。完整约束注释已留在改动处（含 R2 报告 §3.2 引用）。
  2. `DECLB_CACHE` 从 `simpl_decl` 函数体内提升为模块级 thread_local（:996-1000）+ 新增私有
     `declb_cache_clear()`（:1007-1010）；`simpl_decl` 行为不变（同一 TLS，仅声明位置移动；
     原文档注释归属已还原到函数上）。
  3. `PoolState` 的 SAFETY 块注释补一段：声明"最后引用"前提由 Drop 侧主动维护（:3484-3487）。
- **语义安全性**：两表均为纯缓存（丢 memo 重算即得，`force_memo_clear` 本就是
  `clone_prelude_state` 每轮调用的既有函数）；Drop 只在线程退出时运行，RefCell 无重入冲突；
  池满不推时多清一次无害。
- **与 R2 刻画的出入核查**：无出入。R2 即定性为"条件性成立的地雷"（当时无测试触发该初始化序），
  本修复是契约恢复式加固而非行为变更；确认生效需协调者压测（基线 3/3、2/2 崩 → 修复后多次全绿）。
  若压测仍崩，回到 R2 §3.5 的次要假说（并建议按 §3.3 的 `--list` 先核对隐藏测试面）。
- **附带**：清理覆盖了参考版全部持 Rc 的 TLS（FORCE_MEMO + DECLB_CACHE；孪生 FORCE_MEMO 持 V 打包

### 1.3 [P13·已修·追加] enum 隐式无标注域钉 U(0)（A6 矩阵复扫路由，收敛最后阻断项）

- **订正背景**：本报告初版 §2 表把"enum 隐式域钉 U"并入"不适用"——该声明无前轮支撑且与静态证据
  矛盾（触发链在 L13 完整，见 §2 订正行）。L09 R3 先例（工作树未提交改动：`src/L09_mltt/
  elaboration.rs` enum 臂首 + `bump_spine_iter.rs` 同站点）为移植模板。
- **触发链核实（全部在位）**：`parser/mod.rs:1012-1035`（`p_pi_impl_binder` 允许 `[A]` 无标注 →
  `Raw::Hole`，域折入 telescope）；elaboration.rs `fresh_meta`/AppPruning（部分应用 meta `?m A`）；
  `unification.rs:162`（`invert_go` 对非变量 spine 实参 `_ => Err(Stuck)` 硬败）；`check_universe`
  只解洞的类型 meta（域值 meta 仍未解）。机制：多隐式无标注参数（`[A, B]`）时第 2+ 参数域是
  AppPruning 部分应用 meta，使用点显式供给枚举隐式实参（`p1[Nat][Bool]`）需解 `?m A := U(0)`，
  invert 对非变量实参（Nat 的值）硬败 → 误报 can't unify。
- **修法（L09 R3 逐字同构，L13 形态适配）**：
  - 参考版 `elaboration.rs` enum 臂首（:1212+，`match t` 持所有权 → `into_iter` 消耗式重绑）：
    `Icit::Impl && matches!(a, Raw::Hole(_))` → `Raw::U(0)`；L13 适配点：`Raw::Hole(Span<()>)` 带
    payload（matcher 加 `_`）、`Raw::U` 带层级（`U(0)`）、params 名为 `Span<SmolStr>`（用 `Vec<_>`
    规避导入）。宇宙扫描在钉后进行（U(0) 域贡献 lvl 0 = max 恒等，不扰动 universe_lvl）。
  - 孪生 `bump_spine_iter.rs` enum 臂首（:8656+，绑定为引用 → `iter().map` + clone 重绑，L09 孪生
    同款）。两引擎各单一 elaboration 站点（namespace-prefix 的 Decl::Enum 重建走 Raw-map + 重入
    本臂，struct 经 `p_struct` 脱糖为 `Decl::Enum` 同臂受益）。
- **探针**：`tests/l13_fast_parity.rs` `parity_enum_struct_impl_hole_pinned_u0`（L09/L12 同款
  4 源：①多隐式无标注 + 显式实例化 `p1[Nat][Bool] zero true`；②注解处显式实例化 + 全显式构造子
  应用；③struct 脱糖路径 + 投影；④显式标注索引族不受钉影响。is_ok + 双版诊断输出 + parity）。
  L13 语法适配已静态核实：multiline 构造子（`p_enum` 的 `many0_sep(kw(EndLine))`）、构造子级隐式
