## 4. 重点项验证

### 4.1 `mem::forget(check)` 早退分支：无 use-after-move、无新增泄漏隐患
- `src/L01_nbe/bench.rs:884-892`：`if rows.is_empty() { forget(check); println!; return; }`，
  正常出口 `:893` 也 `forget(check)`。两支互斥且早退支以 `return` 发散，**同一
  `check` 不可能既被移动又到达 `:893`**；无 double-free、无 use-after-move。
- 泄漏是**函数既有设计**：函数头 `:710-711` 已声明「check 与每轮 input 都是百万层深
  Box 树，派生 drop 会逐层递归爆栈……用 mem::forget 泄漏，由进程退出回收」；早退支此前
  漏掉该 forget，是 r1 P2（`--only naive --max-church 64000` 类调用会递归析构爆栈）。
  本次补齐是**修复**，非新引入泄漏。
- `bench` 二进制的进程级泄漏可接受（进程退出回收；不属库代码，不影响 L02–L12 运行时）。

### 4.2 `#[repr(align(8))]`（L02/L03）不改变 64 位布局/行为
- L02 `CloCell` 字段 `&str`（x64 16B/align 8）+ `Option<&EnvCons>` + `&Tm`：x64 本就
  size 32/align 8，加 repr 后 size 32/align 8 → **逐字节一致**。
- L03 `CloCell` 字段 `&str`+`Env`(u32,u32,Option<&>)+`&Tm`：x64 align 由 `&str` 决定为 8，
  size 40/align 8，repr 后不变。

  零布局/行为影响。

  不影响任何输出/判定。
