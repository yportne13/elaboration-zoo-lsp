align≥8；`CloCell` 64 位字段全 8 对齐（`Env = {u32,u32,Option<&EnvCons>}`、`&str`、`&Tm`）

niche 布局，无 ABI/序列化影响。断言 `align_of::<T>() >= 8` 在 64 位与 wasm32 均成立。

### 4.4 Stacked Borrows P0：独立最终结论
**同意（在 Stacked Borrows 模型下刻画准确）**，并**明确需要 Miri 才能给出“实际 UB/误编译”
