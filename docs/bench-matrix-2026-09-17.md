## 4. 表注

- 「—」= 不可测：`L05/L06 prune` 参考版超时（archive §4 同）；
  `L10 enum` 孪生发散；`L11/L12 enum` 孪生 check+nf 失败；`L12 traitchain`
  孪生 parity 失败（perf-debt P5）——除 prune 外均为既有 parity 缺口。
- **孪生比参考版慢**的格子（`basic/孪生` < 1）都是既有的层特性，不是本轮引入：
  `L10 match` 0.8×、`L11 match` 0.3×、`L12 match` 0.3×、`L13 match` 0.5×——
  这些负载下参考版反而更快（孪生侧在这几层的 match/quote 路径上没有优势）。
- L11/L12 的 `fast`/`fast_ss` 是**裸**口径（单 decl 检查），`fast_run` 才是与
  `basic` 可比的**全流程**口径；两层 `basic/fast` ≈ 0.3–1.5 与 `basic/fast_run`
  ≈ 2–290 的差别就来自这里。
- L13 的 `prelude-hdl` 是两版都会早 Err 的接线距离负载（量化用），
  `prelude-core`/`examples-hdl` 才是真实用户负载（1.4×/1.4×）。
