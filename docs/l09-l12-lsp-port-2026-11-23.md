## 1. 各层增量（与 L09 的语法面有关）

| 项 | L09–L12 与 L07/L08 的差异 |
|---|---|
| 宇宙 | `U` → **`U(u32)`**（`Type N` 分层）：let 占位用 `Tm::U(0)`；`shape.rs` 的判别用 `Val::U(_)` |
| `Raw::Sum` | 多一个尾字段（universe level）→ raw_span / raw_pretty 用 `.., _` 解构 |
| `Decl` | L10+ 多 `TraitDecl` / `ImplDecl` → `failed_decl_names` 追加两臂（TraitDecl 记 trait 名 + 方法限定键） |
| `Infer` | L10+ 多 `trait_solver` / `trait_definition` / `trait_out_param` / `trait_error` → 观察面字段追加在其后 |
| `Pattern` | 多 `Icit` 字段 → raw_pretty 的模式打印走 Debug 形态（与 L07/L08 同） |

## 2. 落地文件（每层相同）

- `src/<层>/raw_pretty.rs`：源码注解渲染（def 的签名 → 源码文本）；
- `src/<层>/shape.rs`：match 形状登记 + 认回（`FromValue`/`FromType` + `type_level` 优先级）；
- `src/<层>/surface.rs`：`LspSurface` / `SurfaceQuery` / `HoverEntry` / `raw_span` / `inlay_label` /
  `failed_decl_names` / `format_check_warning`（L07 的平移）；
- `src/<层>/mod.rs`：`Infer` 增 `lsp_collect` / `hover_table` / `decl_spans` / `decl_pretty` /
  `decl_shapes`；`run_with_surface` 入口；
- `src/<层>/elaboration.rs`：`render_by_shape` + def 登记（源码注解优先）+ `Raw::Var` 使用处 hover；
- `tests/<层>_lsp_surface.rs`：3 例（源码形态 / 形状认回 / 采集不改 run 输出）。
