## 四、遗留项清单（按优先级）

### HDL

- **0.（新发现，重要）twin def-replay 对新增 prelude def 敏感。**
  hdl-check-graph.typort 新增任意 def 即令 twin 在全部 HDL examples 上
  spine 索引越界（§二-2）。修改既有 def 无恙。这意味着 prelude 并非
  可自由扩展——凡"新增 def"形态的检查规则演进（HDL040+ 的常规做法）
  都会踩雷。需排查 bump_spine_iter 的 def-replay/resident checkpoint
  对 def 数量或 def 插槽的隐含假设（疑似 def 计数上限或 ID 复用）。
- **P0-1 compat 层对 reg 的连续 assign 非法。——已修复（2026-09-29 二轮）。**
  `always @(*)` 内 `y = a & b;`（y 是 output reg）经 pickAssign HDV002
  分支落成普通 assign，旧产码 `assign y = ...` 对 reg 目标非法。经
  iverilog 12（ucrt64）实证：旧产码被拒（"reg y cannot be driven by
  primitives or continuous assignment"）。修复：hdl-verilog.typort 新增
  assignLhsIsReg，assignLineCheck 跳过 reg-LHS 连续发射、
  collectAlwaysBodyLines 把 reg-LHS 裸 assign 收进合并 always @(*) 块做
  阻塞赋值（reg 左值的位选/片选同为过程赋值，一并合法化）；新产码经
  iverilog 编译通过。回归钉
  verilog_compat_tests::m2_comb_reg_assign_routed_into_always_block。
- **~~P0-2 wire 的位选/片选连续 assign 非法。——实证证伪，撤销。~~**
  评审声称 `assign y[3:0] = ...`（net_lvalue 不含位选）被 iverilog/VCS/
  Verilator 拒绝；实测 iverilog 12.0 **接受**该形状（WIRE_EXIT=0），
  Verilator 同样接受，属普遍支持的标准用法。golden 测试
  m2_partsel_write / m2_bitsel_read_write 固化的形状无需改动。评审
  agent 的这条为误报，此处存档更正。reg 侧本就随 P0-1 的过程赋值路由
  合法化。
- **P1-3 复合表达式位选非法。** `(a + b).msb` / `(x << 2).slice[3,0]`
  产 `((a + b))[7]`——表达式位选是 SystemVerilog 扩展。修法：bitsel/
  partsel 的 base 非平面信号时先经 LetNamed 落命名 wire（isDeclaredSignal
  判别已有）。
- **P1-4 asSInt 不引入符号化，`>>>` 退化为逻辑移位。** `b.asSInt >> 1`
  产 `(b >>> 1)`，b 无 signed 声明时按无符号移位——静默错硬件。最小
  修法：SInt `>>`/`|>>` 在 base 非 signed 声明时改用 `{msb, x}` 拼接
  等价式；或 asSInt 产显式符号化节点。
- **P2-6 HDL061 用入边成员冒充可达性。** 与入口断开的环整体漏报
  （3 状态 FSM 仅 s1↔s2 互跳，从复位态 0 永远到不了）。修法：从状态 0
  做边可达闭包再报 `declared ∧ ¬reachable`。
- **P2-7 slice/apply 常量索引越界无检查。** `a8.slice[9, 7]` 静默发射
  越界片选（Verilog 读 x）。修法：新增名字级规则对 GDecl 宽度校验
  （gdeclWidthOf/litNat 零件已在）。
- **P2-8 UInt.expand/resize 是 Expr 层 no-op。** 自决定上下文（拼接、
  let 别名）静默丢位宽：`flag ## a.expand` 产 `{flag, a}` 少 1 位。
  修法：改显式 `{w'{1'b0}, x}`（对齐 SInt.expand 与 `+^` 的既有做法）。
- **P3-9 readSyncCC 忽略跨时钟参数**（文件头自认与 readSync 相同；文档
  已如实标注占位）。接 per-cd 机制即可。
- **P3-10 同名不同参数化模块注册首胜。** `myAdder[8]`/`myAdder[16]`
  只发射一个 def，另一实例端口隐式截断。至少第二次同名注册时报 warning。

### 核心 elaborator

- **F3 DECLB_CACHE 指针键 vs COW 原地变更。** simpl_decl 缓存以 decl
  表指针为键，但 `Cxt::decl`/`fake_bind` 在引用计数为 1 时原地 insert，
  同指针内容漂移 → Match 体 quote/unify 结果依赖声明顺序（不完备方向
  的假 can't unify）。修法：原地变更路径 bump 代数计数器并入缓存键；
  代价是声明密集段的缓存命中率，需 A/B。触发序列依赖具体声明顺序，
  未能离线构造最小复现。
- **F6 check_universe 的 dom>0 臂恒解 U(0)。** 部分应用的宇宙 meta 解
  偏小（保守方向——假错误而非不健全）；L09-L12 的"enum 域洞钉 U(0)"
  修复绕开了主流形态。修法：用 mty 剥 Pi 后的 codomain `U(x)` 构造解。
- 已知未修存量（评审核对与历史文档一致，不重复展开）：preprocess 不
